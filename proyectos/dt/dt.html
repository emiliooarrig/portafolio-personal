Dulce tentación

Dulce Tentación es una pastelería que ofrece una variedad de productos deliciosos y personalizados para satisfacer los gustos de sus clientes. El sitio web está diseñado para brindar una experiencia atractiva y fácil de usar, permitiendo a los usuarios explorar el catálogo de productos y obtener información sobre la empresa.

Mis responsabilidades

Como líder de proyecto, mis responsabilidades fueron:

  • Control de versiones: Utilicé Git y plataformas como GitHub para gestionar el código fuente, creando ramas para nuevas funcionalidades y mantener un historial de cambios.
  • Traducción de Diseño a Código: Convertí los diseños visuales (maquetas) en código funcional utilizando HTML, CSS y JavaScript.
  • Despliegue (Deployment): Fui responsable de desplegar la aplicación en un servicio de hosting (Netlify) para que estuviera disponible públicamente.
