Paideia Nova

Paideia es una plataforma de evaluacion de docentes a nivel universitario, que permite a los estudiantes calificar y revisar a sus profesores de una forma honesta y transparente. El sitio web está diseñado para brindar una opinión confiable sobre aspectos como la calidad de la enseñanza, la claridad en la comunicación entre otros.

Mis responsabilidades

Como desarrollador backend, mis responsabilidades son:

  • Modelado de la base de datos: Diseñé la estructura de la base de datos, incluyendo tablas, relaciones y restricciones, para asegurar la integridad y eficiencia del almacenamiento de datos.
  • Integración del backend con el frontend: Implementé una API RESTful para permitir la comunicación entre el frontend y el backend de la página web.
  • Hosting Configuré y mantuve el servidor web en Hostinger para asegurar que la aplicación esté disponible y funcione de la forma esperada.
